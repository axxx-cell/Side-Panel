# Side Panel

Swipe from the edge to open your favorite apps and quick tools without leaving your current app.

### Features
- Quick app launcher: Claude, Gmail, Chrome, Dola, File Dock and more
- Quick tools: Screenshot, Flashlight, Refresh, Sound
- Shows temperature
- Works on top of any app
- Lightweight and fast

### How to Install
1. Download the APK from Releases on the right side
2. Allow "Install unknown apps" when asked
3. Allow "Draw over other apps" permission
4. Swipe from the right edge to open the panel
